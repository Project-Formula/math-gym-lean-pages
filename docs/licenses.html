项目与单题记录 #

主仓库根目录提供 LICENSE 和 NOTICE。具体题包另有 LICENSE 与 NOTICE。可从题目详情中的「来源说明」进入对应记录。

第三方材料 #

复用或改编时，保留原作者、固定提交或论文版本、许可、必要声明和修改说明。不同来源可能使用不同条款，按实际文件记录核对。
