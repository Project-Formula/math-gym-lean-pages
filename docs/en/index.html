Continue an evaluation #

  • Once one model is configured, run a tier to evaluate a complete set of 20 tasks. To check an installation first, use doctor.
  • Before changing the endpoint or model, read model configuration and provider adapters. Keep a separate run record for each configuration.

Explore tasks and results #

The task catalogue explains how to find a statement, its Lean template and its source. Scoring and results describes the leaderboard and its CSV columns. Use the citation guide to reference the benchmark.
