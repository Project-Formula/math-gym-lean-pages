Quickstart

Take one Tier 1 task, the Freedman martingale tail bound, from environment checks through submission and independent grading.

On this pagePrepare the environmentConfigure one modelRun one taskInspect the result

Prepare the environment #

Use Python 3.11 or later and a running Docker engine. Obtain the project repository and the v2 environment release. Unpack the bundle. Run the commands from the repository root in the same shell, replacing the path with the unpacked directory. On a new machine, follow resource preparation to prepare the cache.

Shell
BUNDLE=/absolute/path/to/lean-core20-evaluation-2h-v2
docker load -i "$BUNDLE/images.tar.gz"

Configure one model #

Copy the model template. Supply the actual model ID, API root and revision. Set the named API key environment variable in your shell. Run doctor to check the images, toolchain and cache.

Shell
mkdir -p .runtime
cp -n problems/theorem-proving/evaluation/model.example.json .runtime/my-model.json
Shell
python3 -m scripts.lean_core_eval doctor --release "$BUNDLE/release" --output .runtime/tier1-doctor

Run one task #

Choose a fresh output directory. This command calls the configured model provider.

Shell
RUN=.runtime/core20-runs/freedman-first
python3 -m scripts.lean_core_eval run --release "$BUNDLE/release" \
  --model .runtime/my-model.json --output "$RUN" \
  --task probability/freedman-martingale-tail

Inspect the result #

Inspect run.json in the run directory. Grade the original submission when one exists, then collect the records. One task supplies a single-task result. To evaluate all 20, see run a tier.

Shell
python3 -m scripts.lean_core_eval grade --release "$BUNDLE/release" \
  --submissions "$RUN/submissions" --output "$RUN/grading"
python3 -m scripts.lean_core_eval collect --release "$BUNDLE/release" \
  --run "$RUN" --output "$RUN/summary.json"
