Run Tier 1 or Tier 2

Both tiers share the per-task budget and proof checks. Each has its own frozen task selection.

On this pageTier 1 · FoundationTier 2 · ChallengeLaunch the challenge tier

Tier 1 · Foundation #

Complete the installation, model configuration and doctor checks in Quickstart. Use the v2 core release and omit the single-task filter to run all 20. When the run finishes, execute the grade and collect commands in the same shell.

Shell
RUN=.runtime/core20-runs/tier1-model
python3 -m scripts.lean_core_eval run --release "$BUNDLE/release" \
  --model .runtime/my-model.json --output "$RUN"

Tier 2 · Challenge #

From the repository root, inspect the next queue in a clean workspace. The full challenge tier contains 20 tasks. Existing valid attempts for the same task version are skipped in later queues. Check the selection, prepare a fresh directory and run doctor.

Shell
python3 -m scripts.theorem_eval plan
ROUND=.runtime/theorem-proving/tier2
python3 -m scripts.theorem_eval prepare --base "$BUNDLE/release" --output "$ROUND"
python3 -m scripts.theorem_eval doctor --release "$ROUND" --output .runtime/tier2-doctor

Launch the challenge tier #

Use a new run name. The driver saves submissions, grades submitted proofs and writes a summary. Repeat the task option to select individual tasks from the queue.

Shell
python3 -m scripts.theorem_eval run --release "$ROUND" \
  --model .runtime/my-model.json --name tier2-model
