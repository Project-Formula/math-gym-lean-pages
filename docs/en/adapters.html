Provider adapters

Chat Completions compatible endpoints can use the built-in driver. Other providers can use a member-supplied adapter.

On this pageRequest and responsePreserve provider stateCheck the integration

Request and response #

The adapter reads one canonical request from stdin and writes one canonical JSON response to stdout. Preserve system and user messages, tool definitions and tool feedback. Specify the command as an argument array. See the configuration example.

Preserve provider state #

Keep native reasoning or signature fields needed for the next turn in private provider_state. Return the actual model ID and token usage. The run record includes the adapter source hash.

Check the integration #

The member template shows the request and response shapes. Implement complete for the chosen provider. Check a normal response and a tool call round trip before the evaluation.
