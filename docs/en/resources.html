Configure and run

Prepare resources

The release bundle, images and dependency cache must match the task statements and evaluation environment.

On this pageImport the releasePrepare or bind the fixed cacheCheck readiness

Import the release #

Unpack the v2 bundle. It includes bundle.json, images.tar.gz, release/ and client/. Compare the image archive's SHA256 with the bundle manifest before importing it.

Shell
BUNDLE=/absolute/path/to/lean-core20-evaluation-2h-v2
docker load -i "$BUNDLE/images.tar.gz"

Prepare or bind the fixed cache #

Use bootstrap on a fresh machine to prepare the pinned Lean toolchain and Mathlib dependencies. If the same versions are already available, use bind-cache with the Linux toolchain and dependency directories. Choose one of the following approaches.

Shell
python3 -m scripts.lean_core_eval bootstrap --release "$BUNDLE/release" \
  --output .runtime/core20-eval-cache
Shell
python3 -m scripts.lean_core_eval bind-cache --release "$BUNDLE/release" \
  --dependencies /absolute/path/to/shared/.lake/packages \
  --toolchain /absolute/path/to/lean-4.33.1-linux

Check readiness #

Run doctor before starting the model clock. If the release, image or cache binding does not match, consult troubleshooting.

Shell
python3 -m scripts.lean_core_eval doctor --release "$BUNDLE/release" --output .runtime/tier1-doctor
