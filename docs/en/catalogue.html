Find a theorem #

Open the task explorer, select a tier and choose a subject. The list is compact. Cards also show the mathematical objective. Open a title to inspect its Lean target and copy a link to the task.

Read the task package #

PROBLEM.md describes the mathematical question. Foundation.lean supplies the allowed definitions. Task.lean contains the declaration to prove. The frozen Lean type specifies the exact parameters, assumptions and conclusion.
