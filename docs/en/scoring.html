Understand evaluation

Scoring and results

Each task has one main theorem. A submission that passes independent verification earns 100 points.

On this pageSingle-task outcomesRead a tier resultInterpret the CSV

Single-task outcomes #

An accepted proof earns 100. A rejected submission or a normally completed attempt with no submission earns zero. Infrastructure errors, pending judgments and unrun tasks remain unscored.

Read a tier result #

A tier has 20 tasks. For example, three accepted proofs give 300/2000 points and a 15% pass rate. Interim records show the number graded and accepted, with the final rate pending. Team-reported aggregates are identified in the source column.

Interpret the CSV #

model includes the version. When the version comes from the provider's description of an API alias, version_note identifies the model string returned during evaluation. Accepted counts the successful tasks, scored counts the recorded judgments and total is the tier size. The pass_rate uses the published denominator. Status and source identify incomplete, completed or team-reported records. Download either the Tier 1 or Tier 2 table.
