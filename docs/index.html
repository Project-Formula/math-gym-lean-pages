Math Gym 定理证明文档

从运行第一道 Lean 题开始，了解模型成绩如何产生，或为题库贡献一个可验收的定理。

本页目录选择下一步继续运行评测浏览题库与结果项目仓库

选择下一步 #

运行评测用基础档的一道 Freedman 鞅尾界题走通环境检查、模型作答和独立判分。快速开始 →理解分数每道题只有一个完整主结论。通过独立验收得 100 分。评分与结果 →贡献题目欢迎提供值得研究的数学结果、可追溯的来源，以及能独立核验的形式化材料。贡献题目或修订 →

继续运行评测 #

  • 准备好一个模型后，按两档题包运行整档 20 题。只想核对环境时，先执行 doctor 检查。
  • 更换接口或模型前，阅读模型配置与适配器。每种配置单独保留运行记录。

浏览题库与结果 #

题目目录介绍如何找到正式题面、Lean 模板和来源。评分与结果说明排行榜和 CSV 的读法。引用指南提供本项目的 BibTeX。
