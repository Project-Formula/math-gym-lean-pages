配置与运行

模型接口适配器

兼容 Chat Completions 的接口可直接使用内置驱动；其他接口可接入成员提供的适配器。

本页目录输入与输出保留供应商状态接入前核对

输入与输出 #

适配器从 stdin 读取一份规范请求，从 stdout 写回单份规范 JSON 响应。保留系统消息、用户消息、工具定义和工具反馈。命令配置使用参数数组，见适配器示例。

保留供应商状态 #

将需要下一轮回传的原生推理或签名字段保存在私有 provider_state。使用真实返回的模型名和 token 用量；适配器源码哈希会随运行记录保存。

接入前核对 #

用成员模板核对输入和返回形状。模板中的 complete 需要实现实际接口。确认一次普通响应和一次工具调用都能往返，再安排正式运行。
