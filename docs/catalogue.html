查找一个定理 #

打开交互题库，选择 Tier 1 或 Tier 2，再选择领域。列表适合查找，卡片同时显示数学目标的简述。点击题名查看目标声明名，复制题目链接可分享同一道题。

阅读题包 #

PROBLEM.md 定义数学任务，Foundation.lean 提供允许使用的基础，Task.lean 包含待完成的声明。完整参数、假设和结论以冻结的 Lean 类型为准。

导出题目清单 #

在首页评测资源下载 JSON 目录，取得每题的标识、难度、领域与目标。使用题目标识将本地 run 或 judge 收据与目录对应起来。
