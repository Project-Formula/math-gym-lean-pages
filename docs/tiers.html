运行 Tier 1 或 Tier 2

两档使用相同的单题预算和证明验收规则，运行入口对应各自的冻结题包。

本页目录Tier 1 · 基础Tier 2 · 挑战运行挑战档

Tier 1 · 基础 #

完成快速开始的安装、模型配置和 doctor 检查。使用基础档 v2 环境并省略单题过滤器，运行全部 20 题。结束后在同一终端执行判分与汇总命令。

Shell
RUN=.runtime/core20-runs/tier1-model
python3 -m scripts.lean_core_eval run --release "$BUNDLE/release" \
  --model .runtime/my-model.json --output "$RUN"

Tier 2 · 挑战 #

从仓库根目录使用定理评测入口，在干净的运行环境查看 next 队列；完整挑战档应有 20 题。已有有效作答的题目版本会从后续队列跳过。确认选题后，在新目录准备题包并运行检查。

Shell
python3 -m scripts.theorem_eval plan
ROUND=.runtime/theorem-proving/tier2
python3 -m scripts.theorem_eval prepare --base "$BUNDLE/release" --output "$ROUND"
python3 -m scripts.theorem_eval doctor --release "$ROUND" --output .runtime/tier2-doctor

运行挑战档 #

使用新的运行名称。驱动保存提交，验收已提交的证明，并写出汇总文件。可用重复的 --task 参数选择队列中的具体题目。

Shell
python3 -m scripts.theorem_eval run --release "$ROUND" \
  --model .runtime/my-model.json --name tier2-model
