模型能看到什么 #

public 容器提供公开定义、模板与 Mathlib 工具。judge 容器持有固定目标并检查最终提交。维护者完整参考证明独立存放。

怎样验收证明 #

检查目标类型、Lean 内核证明和传递公理依赖。占位证明、私自增加公理或改变目标类型均不能通过。可在允许的环境中提交不同于参考解的证明。

检查运行边界 #

维护者使用有效证明、占位符和声明变化等对照检查环境。自检收据用于环境核验。模型成绩来自对应模型的实际提交与 judge 记录。
